# Security policy

This repository holds the GitHub Marketplace listing of Costroid's action. Its one step calls `Costroid/costroid/action` at the commit of Costroid's `v1.0.0-alpha.24`, so a vulnerability here is a vulnerability in Costroid.

Report it through GitHub private vulnerability reporting on Costroid/costroid: open the Security tab at https://github.com/Costroid/costroid/security and choose "Report a vulnerability". Do not open a public issue.

[Costroid's security policy](https://github.com/Costroid/costroid/blob/v1.0.0-alpha.24/SECURITY.md) states the response targets and the scope.
